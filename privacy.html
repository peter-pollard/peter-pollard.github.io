Privacy policy

YouTube Tools · Effective 10 October 2026

This policy describes the personal channel-management tool operated by Peter Pollard for Everyday Microsoft 365 and its public information website.

Data accessed and purpose

The tool uses Google's YouTube Data, Analytics and Reporting APIs. With the owner's authorization it accesses channel identity, uploaded-video metadata, visibility and processing status, and available analytics such as views, watch time, engagement and subscriber changes. Public research reads public video and channel metadata and statistics. It does not access other channels' private analytics.

Upload and video-management permissions allow the tool to transfer owner-selected media and metadata to YouTube, check processing and change approved videos from Unlisted to Public. Each public release requires the owner's separate approval of the finished content and timing.

Storage and retention

Google OAuth tokens are encrypted locally using Windows Data Protection for the current Windows user. The Desktop OAuth client file and API key are stored in a local credential folder. Cached analytics and inventory, encrypted upload-session journals, media, metadata and production/release records are retained locally until the owner removes them. Files saved in the owner's OneDrive workspace may be synchronized by OneDrive under the owner's settings. This public website does not contain credentials, tokens, private analytics or video-upload sessions.

Sharing and service providers

Requests and uploads are sent to Google/YouTube to perform the requested operations. When the owner uses the Codex assistant, selected tool results, analytics, metadata and production material may be processed by OpenAI through Codex under the owner's account settings and OpenAI policies. Credentials and private resumable-session URLs are excluded from normal tool output. Locally synchronized files may be processed by Microsoft OneDrive if synchronization is enabled.

The tool does not sell Google user data, use it for advertising or build a public analytics database. Its use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements. Google user data is used for the channel-management and research functions requested by the owner.

Public website

This website has no sign-in form, tracking scripts, advertising or embedded analytics. It is hosted by GitHub Pages. GitHub may log visitors' IP addresses for security purposes as described in the GitHub Privacy Statement.

Controls, revocation and deletion

The owner can revoke the tool's Google access at Google Account connections. Revocation prevents further authorized API access but does not delete existing YouTube videos or cached files. The owner can remove local credentials, token files, snapshots, upload journals and production records, and remove synchronized copies and backups where applicable. Uploaded videos are managed through YouTube Studio. Questions and deletion assistance can be directed to the contact address below.

Related policies and updates

Use of YouTube is subject to the YouTube Terms of Service and Google Privacy Policy. This policy will be updated when the tool's data practices change; the effective date above identifies the current version.
